# キングショット マスターアカデミー攻略

イスノールとアイナのスキルを比較する非公式の日本語攻略記事です。

## 公開ファイル

- `index.html` — 記事本文とスタイル
- `assets/*.webp` — 記事用のAI制作イラスト
- `assets/social-card.jpg` — SNS・Discord共有用画像
- `.nojekyll` — GitHub Pagesで静的ファイルをそのまま公開するための設定

数値は記事末尾に記載した公開資料を照合したもので、ゲーム内の全スキル表示との照合は未完了です。画像はユーザー提供の設定画を参考に制作したオリジナルイラストで、公式ゲーム画面ではありません。
